PRODUCTION PLATFORM / 2024 — PRESENT

BrainScores

From the scanner to an interactive report, with no one babysitting the cluster.

I built and run the MRI-processing platform at McGill’s MICA Lab. AutoDICOM turns new scans into BIDS every hour. IronFist runs six neuroimaging pipelines in SHA-pinned containers on an SGE cluster, with a run registry, a lab-wide dashboard and a sign-in portal that tracks 1,100+ sessions.

The public side is brainscores.ai on AWS: Next.js, Cognito sign-in, direct-to-S3 uploads, every piece of infrastructure in Terraform, and GitHub Actions deploys with OIDC. A researcher picks a scan and gets a PDF report and a 3D viewer about 40 minutes later.

A 692-session campaign finished in 34 hours after I doubled the cluster throughput. The test suites hold 2,100+ tests.

Python · Snakemake · FastAPI · Next.js · AWS · Terraform · Singularity

Visit brainscores.ai ↗

04

DEEP LEARNING FOR MRI

Models that run on a real cluster

Trained 3D models with PyTorch DDP on four A6000 GPUs: a 66M-parameter residual U-Net with SynthSeg-style domain randomization, and a Neural-ODE mesh-deformation model for cortical surfaces, where I found an adjoint-gradient bug that had silently frozen the encoder. Benchmarked ONNX Runtime and OpenVINO inference for the lab’s segmentation and surface models: 2.4× faster on CPU with bit-identical output.
